Run `npx any-doctor@latest` to get the interactive review. Choose your
doctors and select which ones to run. Review the findings yourself.

You can navigate the tree below with your keyboard.

```text
┌ any-doctor ─────────────────────────────────────────────┐
│                                                         │
│  ▸ async                                      ×5        │
│  ▸ convex                                     ×5        │
│  ▾ slop                                       ×58       │
│      ▾ prefix-overlapping-substring-match     ×2        │
│            src/services/search.ts:12                    │
│            src/services/search.ts:28                    │
│      ▸ named-import-without-reference          ×1       │
│  ▸ openrouter                                 ×2        │
│  ▸ effect-v4                                  ×6        │
│                                                         │
└─────────────────────────────────────────────────────────┘
  ↑↓ move · enter expand · a accept · x not-applicable · c copy · q quit
```

## Keys

| Key | Does |
| --- | --- |
| `up` / `down` (or `k` / `j`) | Move |
| `enter` / `right` | Expand, walk in |
| `left` | Collapse, walk out |
| `a` | Accept the finding as intended |
| `x` | Mark the check not-applicable to this code |
| `v` | Review view — findings with their decision state |
| `u` | Reverse a decision on the selected finding |
| `c` | Copy a fix prompt |
| `q` (or `esc`) | Quit |

## Decisions need reasons

`a` and `x` prompt you for the reason your choices are being made, for
future reference.

## Copy the work for your agent

`c` copies a prompt for you to send to your agent so it can fix.
