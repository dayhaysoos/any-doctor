Not all findings are bad. Some are intentional code the check cannot know
about. A decision records your call so the finding stops being noise.

Two dispositions:

- **accepted** — the concern is real, the code is intentional.
- **not-applicable** — the check's interpretation is wrong for this code.

Both require a reason, and the reason has to be specific enough for a
human to evaluate later.

## Recording one

From the dashboard, press `a` or `x` on a finding and type the reason.
From the CLI (this is what agents use):

```bash
any-doctor decide --key <decisionKey> --accepted --reason "intentional fire-and-forget telemetry"
```

The `--key` comes from the JSON scan output, and it is shell-safe
(base64url). Prefer `--key`: it resolves without re-scanning. The
alternative is coordinate resolution:

```bash
any-doctor decide --file src/services/chat.ts --line 15 --accepted --reason "..." async .
```

## What survives

Decisions attach to a finding's identity — a digest of the check, the
line content, the enclosing function — not to raw coordinates:

- The line moves, the file renames: the decision holds.
- The flagged code changes: the finding resurfaces. You changed the
  evidence; the call gets re-made.
- The doctor's meaning changes: the author bumps the check's `revision`,
  and decisions on the old meaning resurface. Cosmetic doctor edits
  (comments, formatting) do not bump it — decisions survive those.
- Duplicate identical occurrences: held back for you, because one
  decision cannot honestly cover a population it was never evaluated
  against.

## Listing and reversing

```bash
any-doctor decisions           # human table
any-doctor decisions --json    # machine state
any-doctor decisions --reverse <key>
```

State lives in `<dir>/.any-doctor/decisions.local.json` — the directory
you scanned, not the one you ran from. Delete the file and you are back
to raw findings; nothing else holds state.

Decisions never flip a gate: CI always judges [raw
findings](/reference/ci), so dismissing noise cannot fake a clean run.
