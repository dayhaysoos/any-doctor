Not all findings are bad. Sometimes the code is fine and the check can't
tell. A decision is you telling any-doctor to stop bringing it up.

There are two kinds:

- **accepted** — the concern is real, the code is intentional.
- **not-applicable** — the check misread this code.

Both ask for a reason. The reason is kept for future reference.

You decide from the dashboard while you review. Your agent can record
decisions too — the [agent guide](/agents/agent-guide) covers its side
of it.

## What's remembered

A decision sticks to the finding, not to the line number. The code
moves, the file gets renamed — the decision still applies. The finding
only comes back when something actually changed: the code changed, or
the doctor changed what it looks for.

## Changing your mind

Press `u` on a finding in the dashboard to undo its decision. Decisions
live in your repo, in `.any-doctor/`. Delete that file and everything
comes back.
