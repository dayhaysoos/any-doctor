A doctor is a single JS file. No imports, no dependencies, no build step.
It exports a `meta` object and a `doctor(ctx)` function, and that is the
whole contract.

```js
export const meta = {
  id: "my-doctor",
  description: "What this doctor looks for, in one line.",
  severity: "warning",
  blindSpots: [ "what it cannot see" ],
  checks: [
    {
      id: "forgotten-await",
      description: "A call whose result is never awaited.",
      severity: "warning",
      revision: 1,
      claim: "A call to send() in statement position.",
      lookalikes: ["results passed to Promise.all"],
      impact: "Errors vanish; the work is fire-and-forget.",
      why: "send() returns a promise nothing consumes.",
      fix: "Await it or return it.",
    },
  ],
};

export async function doctor(ctx) {
  // read files, search structurally, return findings
}
```

## The confinement

The runtime gives the doctor a read-only `ctx` and nothing else. No
network. No writes. No imports. A doctor can read your files, run
structural searches, and report findings. It cannot phone home, mutate
your repo, or grow dependencies. That is what makes third-party doctors
safe to run.

## Check fields

| Field | What it is |
| ----- | ---------- |
| `id` | Stable check name; appears as `doctor/check-id` |
| `description` | The heading shown for each finding |
| `severity` | `error`, `warning`, or `info` |
| `revision` | Bump when the check's *meaning* changes; cosmetic edits keep it |
| `claim` | The observable condition the check states. Required to certify |
| `lookalikes` | Shapes that look like the claim but are fine |
| `onUnknown` | `"narrow"` or `"skip"` — what to do when the evidence is incomplete |
| `reportingUnit` | `occurrence`, `file`, or `project` — what one finding covers |
| `impact` / `why` / `fix` | The explanation carried into every report and JSON scan |
| `evidence` | Optional range covering the whole flagged expression |

The `claim` is the load-bearing field. A check without a claim cannot be
certified, because eloquent impact prose is not a testable statement.
More on this in [honest checks](/authoring/honest-checks).

## Where doctors live

Three locations, in priority order:

1. `./doctors/` in the repo being scanned
2. `~/.any-doctor/doctors/` (global, `--global` when generating)
3. the bundled pack (lowest priority)

Fixture files (`*.fixtures.mjs`) beside a doctor are its test data, not
target source — scans skip them.
