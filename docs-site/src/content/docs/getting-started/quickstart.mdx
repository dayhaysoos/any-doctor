Run this command in your TypeScript or JavaScript repo.

```bash
npx any-doctor@latest
```

You can choose which doctors you want to run from the interactive picker.
These are sample doctors just to try out.

You can select a specific doctor like this:

```bash
npx any-doctor@latest run async
```

## The agent version

Agents shouldn't be navigating an interactive menu. We support the same
capabilities with a fully JSON experience. Your agent would run the
commands like this:

```bash
npx any-doctor@latest run --all <dir> --format json
```

The [agent guide](/agents/agent-guide) covers the full workflow: scan,
investigate, fix or decide, re-run to verify.

## What you'll see

A scan ends with a report:

```text
Any Doctor — 5 doctors
Score: 95 / 100 — Excellent
187/221 files clean

71 findings  (27 warning, 44 info)
Async: 5 warning
Convex: 5 warning
Slop: 14 warning, 44 info
```

Each finding names the check, the claim it makes, and the exact
`file:line`. The [report page](/scans/report) breaks down every part of
it, including the blind spots every doctor prints about itself.
