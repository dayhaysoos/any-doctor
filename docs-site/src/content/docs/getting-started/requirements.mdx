## Node

Node 18 or newer. That is the only requirement. `npx` works with no
install; `any-doctor` never writes to your repo unless you record
decisions (state lives in `.any-doctor/`).

## ast-grep + oxc parser

The analysis engine ships with the package. We use ast-grep to
determine the shapes of written code and oxc parser for getting more
details. The reports come back in JSON.

## No Network

The doctor runtime has no network access. They only can read your
files. After a run finishes, the CLI sends one anonymous count — which
bundled doctors ran and how many of your own. No code, no names of your
doctors. `ANY_DOCTOR_NO_TELEMETRY=1` turns it off.
