OpenRouter discipline: stream errors surfaced, keep-alives skipped,
cancellations that stop billing.

| Severity | Check | Catches |
| -------- | ----- | ------- |
| warning | `midstream-error-ignored` | A streamed response consumed without checking for mid-stream errors |
| warning | `sse-comment-parse-crash` | A hand-rolled SSE reader that feeds keep-alive comments to `JSON.parse` |
| warning | `missing-abort-signal` | A request sent without an AbortSignal — cancellation keeps billing |
| warning | `retry-after-ignored` | A retry loop that never reads the Retry-After header |
| info | `hardcoded-dated-model-slug` | A dated model slug hardcoded where a maintained alias would survive provider removals |

## Blind spots (the short version)

- OpenRouter context is detected by the file mentioning it anywhere
  (URL, import, baseURL); files routing through an unmarked wrapper are
  not covered.
- Stream-error checks reason per file: an error check living in a
  different file from the consumption loop is not seen.
- Abort and retry checks pair the marker with the call on the same line:
  a multi-line fetch whose URL lands on the next line is not recognized;
  SDK-managed backoff is not recognized.
- Cost/token accounting is deliberately not checked: file-level absence
  reasoning false-positives on apps whose wrapper logs usage elsewhere.
